# While the Lantern Burns

A game for the Ludum Dare #60 compo. Explore dark caverns, keep your lantern charged, and prepare your musket for what waits beyond the light.

## Theme

> "Old tech"

## Goal

My main goal is to make something tiny and original that doubles as a technical and artistic playground for my bigger project [Whisperlands](https://www.youtube.com/@martindzejky). I would also of course like to make something fun and pretty.

## Experiments

These are what I want to try out:

- 2D sprites in 3D world - Inspired by games like Cult of the Lamb and Don't Starve. Until now, I've only ever made fully 2D games. So I want to try out this perspective.
- 2D skeletal animation - Never tried that yet in Godot. Previously I used simple 2D sprites, animations were procedural and used a few sprite frames.
- Generated audio effects - This is just something I want to experiment with out of curiosity. Is it any good? Can it replace searching for sound effect samples?

## Tech

- Godot - My trusty game engine I love.
- Procreate - Drawing 2D art for the game.
- Notion - Writing notes, planning.
- VS Code - My code editor of choice.
- Codex - Coding agent writing the code (I make the choices).
- ElevenLabs - Platform I want to experiment with generating the sound effects and perhaps ambience for the game.
- Ableton - Making music for the game, editing audio, composing sounds.
